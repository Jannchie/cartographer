# Cartographer

程序化的虚构世界地图生成器。输入一个种子，就能生成一个有板块构造、侵蚀地貌、气候与水系的世界，可以用 3D 沙盘或纸质地图两种方式查看。

```bash
pnpm install
pnpm dev        # http://localhost:5190
```

## 生成流程

| 阶段 | 做法 |
| --- | --- |
| 大陆与山脉 | 用扭曲 Voronoi 模拟板块；汇聚边界隆起造山带（陆-陆碰撞抬升更高，洋-洋碰撞形成岛弧），离散边界在陆上形成裂谷、在洋底形成洋中脊；海岸线由两级域扭曲的分形噪声决定 |
| 海底 | 按离岸距离塑造大陆架、陆坡和深海平原；主动大陆边缘的陆架较窄，外侧有海沟；热点火山岛链沿板块运动方向逐渐老化、下沉成平顶海山 |
| 盆地 | 在大陆腹地压出凹陷，四周加一圈山地边缘 |
| 侵蚀 | ① 先在粗网格上用流水功率定律做"构造抬升 ↔ 流水下切"的隐式迭代，得到树枝状的山谷和山脊；② 再在全分辨率上做细化，并叠加雨滴侵蚀（冲沟、冲积扇）和热力风化 |
| 气候 | 年均温由纬度、海拔递减率和大陆度决定；水汽沿行星风带推进，迎风坡降雨、背风坡形成雨影，再叠加 ITCZ、副热带高压和西风带的纬向调制 |
| 水文 | 用 Priority-Flood 填洼并求流向，径流按 Budyko 关系估算。洼地做水量平衡：来水多于蒸发的注满后外泄，少于蒸发的退缩成内流湖或盐沼 |
| 群系 | 用 Whittaker 式的气温-降水分类，另外判定高山裸岩、海滩、湿地和盐沼 |
| 注记 | 每个世界随机生成一门"语言"来命名大陆、海洋、山脉、湖泊、沙漠和城市；城市按宜居度选址（河流、海港、平坦程度、气候） |

## 视图

- **3D 沙盘**：地形网格带实时阴影；水面着色器实现水深渐变、菲涅尔反射、太阳高光、近岸浪花和海冰；森林群系里放了针叶树和阔叶树的实例；沙盘四周有地层剖面。垂直夸张、太阳方位和太阳高度都可以调。
- **制图**：六种纸质地图风格，都自带注记避让、比例尺、图名和图框：

  | 风格 | 特点 |
  | --- | --- |
  | 自然地理 | 分层设色的海洋与等深线、岸线外的水线、群系水彩底色 × 多方向山体晕渲、500 m 等高线 |
  | 奇幻羊皮 | 羊皮纸、水渍与焦边；手绘山峰（背光面排线）、丘陵、针叶/阔叶树、沙漠点彩、沼泽草丛；卷轴图名、百合花饰罗盘、城堡式城市符号 |
  | 航海图 | 10/20/50/200/1000 m 等深线与浅海分层蓝、测深数字、两组 32 方位恒向线、360° 刻度罗盘 |
  | 政区图 | 以都城为种子按地形代价扩张出国家，国界落在山脊、大河与海峡上；相邻国家不同色、国界内侧晕边、点划国界、国家图例 |
  | 水墨 | 宣纸纤维、青绿山水淡彩、干笔皴擦、鱼鳞水波；中文地名（大陆、海洋、山脉竖排），竖排题名与朱文印 |
  | 等高线 | 现代地形图：100 m 首曲线 + 500 m 计曲线（过密时自动省略首曲线）、冰川蓝色等高线、林地绿底、分层设色图例 |

参数会同步到 URL hash，分享链接就能复现同一个世界。不同 JS 引擎的 `Math.exp/pow` 末位精度可能不同，经侵蚀迭代放大后，跨浏览器内核打开同一链接，地形会有细微差别。

## 离线调参

```bash
pnpm preview:png <seed> out.png   # 群系预览 + 各阶段耗时与统计
pnpm shade:png <seed> out.png     # 纯地形晕渲
pnpm atlas:png <seed> physical,ink <outDir> [x,y,w,h]   # 离线渲染纸质地图（可裁剪原尺寸局部）
```
